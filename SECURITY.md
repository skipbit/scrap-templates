# Security Policy

## Supported Versions

No releases have been published yet. Security fixes are applied to the `main` branch.

| Version | Supported |
|---------|-----------|
| `main`  | Yes       |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public issues or pull requests.

Report them privately through GitHub's private vulnerability reporting:

1. Open the [Security tab](https://github.com/skipbit/scrap-templates/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, the affected template, and the steps to reproduce it.
